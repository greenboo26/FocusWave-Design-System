## 初版特征

初版采用“潮汐风”视觉：天青—薄雾绿—暖沙渐变背景、玻璃卡片、左侧导航、中央呼吸圆、HR/HRV/RR/Movement 信息、SART 任务状态与胸壁微动波形。它奠定了“安静、克制、自然光感”的方向，但后续设计已明确不再以卡片堆叠、玻璃拟态和冥想 App 式呼吸圆作为首屏核心。

后续版本必须放在新的原型目录中，不得修改本归档文件，以便始终能比较设计演进。
