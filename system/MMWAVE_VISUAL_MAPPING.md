# mmWave → Visual Mapping

目标：让 FocusWave 的艺术流场不是装饰动画，而是由真实毫米波与派生特征驱动的可解释视觉。

## 映射原则

1. 先保留数据结构，再进行审美压缩；不能先画一个漂亮图形再给它编数据解释。
2. 不要求每一根线对应一个物理量，但每类视觉变化应有明确的数据来源。
3. 数据质量差时，应让画面表现“不确定”而不是错误地表现“分心”。
4. 视觉映射参数需可记录、可复现，后续可用于会话回放与 3D Attention Portrait。

## 第一版映射表

| 数据 / 特征 | 视觉维度 | 说明 |
|---|---|---|
| unwrapped phase | 主流线位移场 | 决定局部位置偏移与缓慢形变 |
| respiratory component | 大尺度曲率 / 周期 | 呼吸越慢，波峰间距越宽；振幅影响大尺度起伏 |
| heartbeat micro-motion | 二级细纹 | 只作为极细、低对比微纹理，不抢主结构 |
| beat / IBI | 局部节律点 | 可影响细纹间距，避免直接画心电图式尖峰 |
| HRV | 微尺度节律不规则度 | 只在数据质量充分时使用，不将高低直接等同于专注好坏 |
| movement | 局部偏折 / 断续 / 剪切 | 体动首先是质量与干扰变量，不直接渲染成“分心” |
| coverage / valid-window | 透明度 / 完整度 | 覆盖下降时，线场局部缺失或变淡 |
| signal confidence | 线条稳定度 | 置信度低时弱化确定性，不用红色报警覆盖主视觉 |
| focus stability | 全局方向一致性 | 越稳定，长线越连续、全局流向越一致 |
| attention drift | 局部相位错位 / 小涡旋 | 游移表现为少量局部扰动，避免满屏混乱 |
| refocus transition | 扰动向统一流向恢复 | 恢复过程应是连续动画而非状态页面瞬切 |

## 视觉状态不是单变量阈值

“稳定 / 轻度游移 / 明显分散 / 重新聚焦 / 疲惫”应来自状态模型或多指标组合，而不是直接按某一个 HRV、HR 或呼吸阈值生成。

## 待实验确认

- 每个视觉参数的平滑时间窗
- 状态变化的 hysteresis，避免 UI 高频抖动
- movement 与 attention 的解耦策略
- 数据质量不足时的降级模式
- 2D 流场到 3D Attention Portrait 的空间定义
