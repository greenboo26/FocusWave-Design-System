# Visual Language

FocusWave 的视觉语言由五个核心要素构成：留白、数据流场、自然色域、人文文字、科学锚点。

## 1. 空间

页面采用大面积暖白或纸白背景。留白形成静度与呼吸感，也让毫米波流场成为清晰的视觉中心。

首屏保持稳定的左文右波结构：

- 左侧约承担状态、人文语义与轻量解释
- 右侧约承担实时数据艺术
- 顶部承担会话上下文
- 底部承担科学锚点

## 2. 数据流场

流场采用细、轻、连续的线条。几何保持有机、非对称、局部复杂、整体克制。

形态来源包括：

- 大尺度呼吸周期
- 微尺度心搏纹理
- 相位位移
- 运动剪切
- 状态秩序度
- 置信度与有效覆盖

流场在时间上连续演化，状态迁移表现为视觉参数缓慢变化。

## 3. 材质感

整体材质接近纸、雾、石、空气与细墨线。视觉表面保持轻、哑光、低反射感，形成安静而精确的研究气质。

## 4. 色彩

基础背景保持暖白。主题色域由意象世界决定，状态通过明度、饱和度、综合色比例、局部对比和统一程度调节。

色彩使用以柔和、低刺激、可长时间观看为默认目标，同时保留足够的冷暖差异，让山、海、竹、雨、线香、夕照、花、夜形成可辨识的世界。

## 5. 人文文字

状态标题与短句具有自然书写感和适度尺度。文字与流场共同构成视觉叙事：文字负责命名感受，流场负责展示数据结构。

## 6. 科学锚点

`Focus Index / Confidence / Data Quality` 保持轻量、清晰、低存在感。二级页面展开 raw signal、features、quality、算法版本与验证状态。

## 7. 意象转译

意象通过数据行为进入画面：

- 山 → 隆起、承托、稳定重心
- 海 → 横向推进、潮汐周期、回卷
- 竹 → 节律、挺拔方向、重复结构
- 雨 → 点状扰动、扩散、细密节拍
- 云 → 宽尺度漂移、柔和形变
- 飞鸟 → 轨迹迁移、向外运动
- 白马 → 连续快速的方向迁移与较强动势
- 线香 → 缓慢上升、内收、持续
- 花 → 舒展、展开、局部回升
- 月 / 夜 → 深色域、低唤醒、内收

## 8. 品牌气质

FocusWave 的品牌感来自“看见不可见的专注变化”。整体体验同时具有研究工具的精确感、数据艺术的独特性和人文阅读的余韵。
