# FocusWave Design Decision Log

该文件记录设计演进中的关键决策、参考方向、取舍理由和被否决路径。目标是让后续 ChatGPT / Codex / 人类设计协作者不依赖聊天记录也能恢复设计上下文。

---

## D-001 初版定位：从冥想式仪表盘转向数据艺术界面

**起点**：初版 `archive/initial-prototype/index.html` 使用天青—薄雾绿—暖沙渐变、玻璃卡片、呼吸圆、左侧导航与多指标信息。

**问题**：完整、专业，但视觉上接近 wellness / meditation SaaS，缺少 FocusWave 自身辨识度；首屏信息过多，卡片和呼吸圆争夺视觉中心。

**决策**：首屏从“仪表盘”转成“数据作品”。保留研究可信度，但让毫米波数据成为主视觉。

---

## D-002 放弃 AI 假摄影

曾尝试以“学生专注学习”的写实 AI 摄影作为首屏情绪载体。

**否决原因**：

- 假摄影感明显，容易廉价
- 与毫米波数据产品的独特性无关
- 抢夺了真正应该成为主角的数据
- 难形成稳定的品牌视觉系统

**结论**：不使用 AI 写实人物摄影作为核心视觉。

---

## D-003 放弃抽象 blob、对称蝴蝶形和纯数学同心圆

曾探索抽象有机形、对称等高线和同心圆扩散。

**否决原因**：

- blob 具有明显的生成式 AI 装饰感
- 对称等高线容易像蝴蝶 / 图标，不像活的数据
- 同心圆容易像声呐、雷达 UI，过于直接和科技模板化

**结论**：视觉必须保留真实数据的不完全、非对称和局部扰动。

---

## D-004 建立“留白 + 左文右波”的母版

探索中形成一版获得认可的结构：

- 近纸白背景
- 极大留白
- 顶部极简会话信息
- 左侧状态文本
- 右侧毫米波细线场
- 底部 Focus Index / Confidence / Data Quality

**决策**：该结构成为当前首屏母版。后续主题与状态变化不应随意改变版式。

---

## D-005 枯山水不是装饰，而是视觉思想

曾把枯山水理解为“砂、石、池塘、波纹”等实体元素直接拼入 UI，结果僵硬。

**问题**：这是元素拼贴，不是数据融合。

**新解释**：借用枯山水“以有限痕迹表现不可见流动”的思想。毫米波本身生成类似耙砂的连续线场，而不是在界面里放一座禅庭。

**允许**：线场具有砂纹般的秩序、留白、回旋、疏密。

**不允许**：为了禅意而加石头、香炉、小桥、池塘、写实庭院。

---

## D-006 意象从“图片主题”改为“数据行为主题”

用户提出山、海、竹、雨、云、飞鸟、白马、蜻蜓、花、线香、禅寺、波浪等意象。

曾错误尝试直接把山水、竹林、香炉、花枝放入页面背景。

**否决原因**：破坏留白和数据主角地位，变成东方水彩皮肤。

**决策**：意象只影响：

- 流线几何
- 流线节律
- 局部扰动方式
- 色域
- 状态短句与文化文本

不直接生成写实场景。

---

## D-007 颜色不等于状态标签

早期配色过度集中在灰绿、灰蓝、米白，主题间区分不足。

**决策**：建立冷、暖、中性多个色域；意象决定基础色，状态决定该色域的明度、纯度、秩序和局部对比。

示例：

- 海：雾蓝 / 灰蓝
- 山：苔灰 / 松绿
- 竹：竹青 / 米灰
- 雨：铅蓝 / 冷灰
- 线香：浅赭 / 檀木灰 / 琥珀
- 夕照：淡杏 / 暮紫灰
- 花：灰粉 / 淡胭脂
- 夜：深靛 / 银灰

颜色干预必须标为“文献启发型”，不能宣称某色必然提升专注。

---

## D-008 字体：数据层与人文层分离

传统宋体 / 黑体作为状态标题显得生硬；系统楷体又容易古风化。

**决策**：

- 状态标题与文学短句：优先测试现代文楷 / 今楷，保留书写感但适合屏幕
- 数据、英文、时间、指标：现代 UI 字体 / 数字字体
- 不使用印章作为装饰

原则：**数据是现代的，人文是有温度的。**

---

## D-009 文本系统从“今日判词”扩展为跨文化 Text / Quote Engine

最初考虑中文诗词、俳句与判词，后续扩展为多语言文化文本。

**决策**：建立审核型文本库，允许中国古典、日本文学、英语文学、欧洲哲学及其他合适文化来源；显示原文 + 中文翻译 + 作者 / 出处。

AI 可以根据状态生成 FocusWave 原创短句，但不得伪造名言。

---

## D-010 二维实时流场 + 三维 Attention Portrait

用户提出 3D 可拖动视角的“专注画像”。

**决策**：

- 2D 流场：实时、此刻、轻量
- 3D Attention Portrait：会话级、可旋转、形成独特的个人数据雕塑
- 科学详情：Raw / features / quality 作为第三层证据

3D 仍保持纯数据，不做景观模型。

---

## D-011 被明确禁止的视觉习惯

以下方向除非后续明确推翻，否则默认禁止：

- 卡片堆叠作为首屏主体
- AI 假摄影
- 闪粉、光尘、随机粒子、漂浮微光
- 霓虹科技光效
- 装饰性印章
- 写实山水 / 水彩背景拼贴
- 字体全部古风化
- 巨大标题与巨大分数同时抢视觉中心
- 对称蝴蝶状数据图形
- 单纯声呐式同心圆
- 为“禅意”强行加入石头、香炉、寺院等实体物件

## D-012 当前下一步

1. 在锁定母版上测试现代文楷 / 今楷的状态标题与短句。
2. 设计冷色、暖色、中性色的状态变体，但版式保持一致。
3. 建立真实毫米波参数 → 流线参数映射表。
4. 建立意象词库与跨文化文本库的数据结构。
5. 研究颜色、明度、饱和度与持续注意 / 唤醒 / 走神之间的文献，区分设计启发与已验证干预。
6. 设计 Attention Portrait 的 3D 数据空间定义。
