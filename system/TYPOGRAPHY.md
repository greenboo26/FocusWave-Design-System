# Typography

## 核心原则

FocusWave 的字体系统分为“数据层”和“人文层”。

### 数据层

用于：

- Focus Index
- Confidence
- Data Quality
- SART / LIVE / 时间
- 参数、单位、标签

要求：现代、清晰、精确、低存在感。优先使用稳定的 UI 无衬线 / 数字字体体系。

### 人文层

用于：

- `专注维持 / 轻度游移 / 明显分散 / 重新聚焦`
- 判词、短句、文学引用与译文

要求：有书写感但不做传统古风。优先测试现代文楷 / 今楷方向。

## 当前候选方向

- 霞鹜文楷 Screen：作为屏幕文楷参考候选
- 仓耳今楷：作为现代楷体参考候选
- 后续可测试更轻、更克制的书写标题字

## 明确否决

- 整个 UI 全部使用楷体
- 默认系统楷体直接套用
- 状态标题继续使用生硬的普通宋体 / 黑体
- 毛笔书法式巨大标题
- 装饰性印章

## 版面建议

状态标题可以明显大于其他文本，但不能同时与巨大分数争抢视觉中心。判词应比标签显著，但仍留足呼吸空间。

原则：**数据是现代的，人文是有温度的。**
