# Session Setup Choice Controls

## 目标

Session Setup 使用一套统一的产品级选择语言，让用户在开始学习或工作前快速完成配置，同时保持 FocusWave 的低刺激、人文与数据艺术气质。

## 控件映射

### 计划时长

采用轻量分段选择：`25 分钟 / 45 分钟 / 60 分钟 / 自由专注`。

选择结果直接写入 `FocusSessionConfig.duration_minutes`。选中态通过柔和底色、细描边与文字对比表达。

### 意象主题

采用带微型视觉预览的主题卡。每张卡同时表达主题名、基础色域与视觉气质。

当前主题：

- 海 · 雾蓝：流动、清透
- 山 · 苔绿：稳定、承托
- 线香 · 浅赭：内收、持续
- 夕照 · 淡杏：温暖、回收

选择结果写入 `FocusSessionConfig.visual_theme`，并驱动后续 Live Focus 的流线色域与主题行为。

### 调节方式

采用三档语义卡：

- 安静：以记录为主，界面保持最低存在感
- 温和：持续游移时提供轻量调节入口
- 主动：更早提供恢复支持

每个选项同时展示名称与行为说明，使选择表达用户偏好，而不是抽象设置值。

### 文字模式

采用四个轻量文字标签：

- 极简
- FocusWave 原创
- 世界文学
- 中文古典

每项同时说明内容来源与显示方式。选择结果进入内容层，而科学推理结果保持独立。

## 统一交互原则

所有选择控件共享以下行为：

1. 点击整个选项区域即可选择。
2. 当前选择具有明确但低刺激的视觉反馈。
3. 用户在进入 Device Ready 前即可看到全部关键配置。
4. 每个控件直接对应结构化 `FocusSessionConfig` 字段。
5. 选项的视觉表达与其语义保持一致，减少表单感，强化 session 启动体验。

## 当前实现

`prototype/daily-focus-v1/index.html` 已采用上述控件体系，并通过统一的 `data-value` + selected state 管理选择结果。
