## 初版特征

初版采用“潮汐风”视觉：天青—薄雾绿—暖沙渐变背景、玻璃卡片、左侧导航、中央呼吸圆、HR / HRV / RR / Movement 信息、SART 任务状态与胸壁微动波形。

它为后续设计提供了三项重要起点：

1. 安静、克制、自然光感的整体气质
2. 毫米波生理信息与注意状态共同呈现的产品结构
3. 实时监测、报告、历史、训练与设置等功能范围

当前设计主线在这些产品基础上进一步强化数据原生视觉、留白、人文文本与可解释的数据艺术。
