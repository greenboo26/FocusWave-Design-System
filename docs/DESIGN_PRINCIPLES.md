# FocusWave 设计原则

状态：Working Baseline / 持续迭代

本文件记录当前已经形成共识、后续设计默认遵守的原则。若要突破其中任何一条，需要在 `DESIGN_DECISIONS.md` 中写明原因。

## 1. 首屏不是仪表盘，而是一幅正在生成的数据作品

FocusWave 的第一视觉中心必须是毫米波数据本身，而不是卡片、分数、头像、图标或装饰插画。

首屏优先级：

1. 毫米波生成的艺术流场 / 数据形态
2. 当前注意状态与一条人文文本
3. 极少量可信度与数据质量信息
4. 其他专业指标进入二级详情

## 2. 锁定的母版骨架

当前首屏母版保持以下结构：

- 大面积暖白 / 纸白留白
- 左上：FocusWave 标识
- 顶部中间：任务名、时间、LIVE 等极简会话信息
- 左侧：状态名称、状态副句、人文短句 / 引文
- 右侧：大面积毫米波细线流场
- 底部：`Focus Index / Confidence / Data Quality`

布局本身应稳定。不同状态与不同意象世界主要通过流线、色彩、文字发生变化，而不是每次换一套页面结构。

## 3. 数据是现代的，人文是有温度的

界面分为两套视觉语言：

- 数据层：克制、现代、精确、轻量，使用现代 UI 字体与数字字体。
- 人文层：允许文楷、今楷或具有书写感但仍适合屏幕的字体，用于状态标题与短句。

不能让楷体覆盖整个产品，也不能把所有文字都做成古风。

## 4. 意象不是背景图库

山、海、竹、雨、云、飞鸟、蜻蜓、线香、花、月、禅庭等意象，不应被直接画成写实风景或水彩背景。

正确方式：让意象改变毫米波数据流线的行为、色彩、疏密、方向性与文本语义。

例：

- 山：低频隆起、重心稳定、长线连续
- 海：横向推进、潮汐式周期、局部回卷
- 竹：节律清晰、方向更挺拔、重复性更强
- 雨：局部点状扰动与扩散，但仍由数据线形成
- 飞鸟：局部轨迹外散、重心迁移
- 线香：缓慢上升与内收，不直接画香炉

## 5. 毫米波参数必须真正参与视觉生成

艺术化不能只是“看起来像数据”。可视形态需要尽量对应真实特征。

建议映射：

- 呼吸频率 → 大尺度波纹周期
- 呼吸振幅 → 大尺度起伏幅度
- 心搏 / beat 微动 → 极细的二级纹理
- HRV / IBI 变化 → 局部间距与细纹节律变化
- 相位解缠 → 局部位移 / 流向
- movement → 局部破坏、偏折、断续
- 信号质量 → 线条完整度、透明度、噪声阈值
- 专注稳定性 → 全局秩序、方向一致性、聚合度
- 注意游移 → 相位错位、小型涡旋、局部外散
- 重新聚焦 → 从局部扰动向整体秩序恢复

## 6. 颜色是主题语言，也是潜在调节变量

不把“专注=蓝绿色”写死。

颜色系统分两层：

- 意象基础色：山、海、竹、雨、线香、夕照、花、夜等决定不同色域。
- 状态调节：专注稳定、游移、分散、恢复、疲惫决定明度、饱和度、纯度、局部对比和色彩统一性。

允许冷色、暖色、中性色共同存在，但始终低饱和、低刺激、服从留白。

## 7. 文本系统可以跨文化，但必须可核验

文本不局限于中国诗词或“判词”。可包含：

- FocusWave 原创短句
- 中国古典文学
- 日本文学 / 俳句
- 英语、法语、拉丁语、希腊哲学等可核验短句
- 其他文化中与专注、心绪、澄明、游移、归返相关的经典文本

规则：

- 必须标明作者与出处（如为引用）
- 多语言需附中文翻译
- 不采用网络伪名言
- 避免宗教宣教、政治立场、宿命论、死亡暗示等高争议内容
- AI 生成内容必须明确标记为原创生成，不冒充名著原句

## 8. 3D Attention Portrait 是二级体验，不抢首屏

二维首屏负责“此刻”；3D 专注画像负责“这一段会话”。

3D 版本应为纯数据生成的浮雕 / 地形表面，可拖动旋转，但不加入石头、小桥、假山、河流、闪粉、粒子或 AI 风景。

## 9. 必须保留研究边界

FocusWave 是研究原型。界面应始终区分：

- 测得的信号
- 推导的特征
- 探索性综合指标
- 尚未验证的状态解释

不能把探索性分数包装成临床诊断、人格判断或已经建立的常模结论。
