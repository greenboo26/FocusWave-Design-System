# FocusWave Design System

FocusWave 独立设计系统仓库。这里记录界面设计原则、视觉语言、研究依据、设计决策、被否决方向与原型演进，不存放实验程序代码。

## 当前目标

建立一套以毫米波数据形态为核心、兼具科学可解释性与人文艺术表达的专注状态界面系统。

## 仓库结构

- `archive/initial-prototype/`：最初收到的界面原型，原样归档，不作为当前设计定稿。
- `docs/DESIGN_DECISIONS.md`：持续更新的设计决策日志。
- `docs/DESIGN_PRINCIPLES.md`：当前锁定的设计原则。
- `docs/RESEARCH_REFERENCES.md`：字体、色彩、注意调节、文化意象等参考来源。
- `system/`：布局、字体、颜色、毫米波视觉映射、意象与文本生成规则。
- `rejected-directions/`：明确被否决的方向及原因，避免后续重复踩坑。

## 当前母版方向

首屏以大面积留白为基础；顶部仅保留极简任务信息；左侧为状态与短句；右侧以毫米波数据生成的细线流场为唯一主视觉；底部保留 `Focus Index / Confidence / Data Quality`。意象通过流线形态、配色与文本被暗示，而不是直接把山、海、竹、禅寺等画成背景插画。
