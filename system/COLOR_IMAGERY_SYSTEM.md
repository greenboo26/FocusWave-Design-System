# Color & Imagery System

颜色不是单纯状态标签，也不是换肤。FocusWave 使用“意象基础色 × 状态调节”的两层系统。

## 意象基础色

| 意象世界 | 基础色域 | 视觉气质 |
|---|---|---|
| 海 | 雾蓝 / 灰蓝 / 珍珠白 | 流动、呼吸、回返 |
| 山 | 苔灰 / 松绿 / 岩灰 | 稳定、承托、持久 |
| 竹 | 竹青 / 米灰 / 墨绿 | 清晰、节律、克制 |
| 雨 | 铅蓝 / 冷灰 / 月白 | 局部扰动、恢复、清凉 |
| 云 | 银灰 / 淡蓝灰 / 薄白 | 漂移、发散、朦胧 |
| 线香 | 浅赭 / 檀木灰 / 淡琥珀 | 内收、沉静、持续 |
| 夕照 | 淡杏 / 陶土灰 / 暮紫灰 | 回收、温暖、阶段结束 |
| 花 | 灰粉 / 淡胭脂 / 嫩绿 | 舒展、恢复、积极回升 |
| 夜 / 月 | 深靛 / 墨紫 / 银灰 | 深度、低刺激、内省 |
| 禅庭 / 石 | 米白 / 砂岩 / 石灰 / 墨灰 | 留白、秩序、静观 |

## 状态调节

同一个意象主题内，状态主要通过以下维度变化：

- 稳定：色彩关系统一、低饱和、低对比、线场连续
- 轻度游移：局部色相或明度轻微偏离、少量小涡旋
- 明显分散：局部综合色增加、秩序下降，但不使用强烈红色报警
- 重新聚焦：色彩重新统一、重心回收、清晰度逐渐提高
- 疲惫：整体更灰、更浑浊、对比更弱；若进入调节模式可适度提高亮度与清透度

## 颜色研究边界

颜色可能影响唤醒、动机和任务表现，但效应受任务、文化、亮度、饱和度与情境影响。系统只能使用“文献启发型调节主题”的表述，不能宣称某种颜色必然提升专注。

后续应把颜色调节作为可验证的 A/B 或被试内实验因素，而不是未经验证的产品事实。
