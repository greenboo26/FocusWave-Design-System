# Typography

## 核心原则

FocusWave 使用“数据层 + 人文层”的双字体系统。

### 数据层

服务内容：

- Focus Index
- Confidence
- Data Quality
- SART / LIVE / 时间
- 参数、单位、标签

视觉要求：现代、清晰、精确、轻量、适合长时间屏幕阅读。优先使用成熟的 UI 无衬线字体与稳定的数字字形体系。

### 人文层

服务内容：

- `专注维持 / 轻度游移 / 明显分散 / 重新聚焦`
- FocusWave 原创短句
- 文学引用与译文

视觉要求：自然书写感、温度、屏幕适配性、清晰的汉字结构。优先测试现代文楷 / 今楷方向。

## 当前候选

- 霞鹜文楷 Screen：屏幕文楷参考候选
- 仓耳今楷：现代楷体参考候选
- 更轻、更克制的书写标题字：后续对比方向

## 字体层级

- 状态标题：人文层最大字号，承担状态命名
- 判词 / 短句：人文层第二层级，承担情绪与哲理表达
- 状态副句：轻量辅助文字
- 指标数字：数据层高可读数字
- 指标标签 / 时间 / LIVE：数据层小字号

页面保持单一主视觉中心。状态标题具有足够辨识度，指标保持轻量，流场继续承担主要视觉面积。

原则：**数据是现代的，人文是有温度的。**
