# FocusWave State Language System

## 目的

FocusWave 的状态文字承担两个同时存在的任务：准确表达注意状态，并维持低干扰的人文体验。文字层读取成熟模型输出后的结构化 `AttentionState`，不参与状态判定。

当前语言系统先围绕四个核心阶段建立：

1. 专注维持：持续注意已经稳定落在当前任务上。
2. 轻度游移：注意开始离开当前任务，但仍保持较强可返回性。
3. 状态起伏：注意分散到多个方向，当前任务的注意占比明显下降。
4. 重新聚焦：注意已经觉察偏移，并重新回到任务或调节锚点。

这一结构与 focused-attention meditation 文献中的持续聚焦、觉察分心、脱离干扰、返回锚点过程一致；acceptance 研究提示，回收阶段的语言应包含允许和重新定向，而不是制造自我评价。

## 四种状态的语言功能

### 专注维持

语言目标：确认稳定，同时降低额外刺激。

句法特征：完整、平缓、陈述式；节奏长；动词数量少；空间关系清晰。

意象行为：平、定、收、沉、清、长。

示例：
- 海：潮线平直，远处的声响也退下去了。
- 山：山脊沉静，目光停在一处。
- 线香：烟线向上，细而不乱。
- 夕照：余光落在桌面，世界慢慢收窄。

### 轻度游移

语言目标：让用户感到“注意正在移动”，同时保留可返回性。

句法特征：出现方向变化和轻微位移；保持单一主意象；避免灾难化程度词。

意象行为：偏、随、过、移、松、远。

示例：
- 海：一念随潮走远，岸还在视野里。
- 山：一片云越过山腰，视线跟着走了半程。
- 线香：一缕烟偏向窗边，心也跟过去一点。
- 夕照：暮色向外铺开，注意也松了一寸。

### 状态起伏

语言目标：表达当前注意结构出现分散和多方向竞争。

句法特征：复数关系、分叉、边界模糊；节奏比稳定态更短、更有断裂感。

意象行为：散、拆、漫、分、切、并起。

示例：
- 海：风把水面拆成许多方向。
- 山：岚气漫开，峰与峰之间失了边界。
- 线香：烟迹散开，几条念头同时升起。
- 夕照：云层把光切成许多片，思绪随之散开。

### 重新聚焦

语言目标：表达觉察已经发生，并将注意重新指向可感知的锚点。

句法特征：先描述变化结束，再出现轮廓、方向或落点恢复；语气具有完成感。

意象行为：回、收、显、落、归、清。

示例：
- 海：潮水回身，岸线重新清楚。
- 山：云从峰前移开，轮廓重新显出来。
- 线香：风停之后，烟又收成一线。
- 夕照：最后一束光重新落回眼前。

## 主题与状态分离

主题决定语义世界，状态决定该世界中的行为变化。

因此同一状态在不同主题中采用不同的空间机制；同一主题在不同状态中保持连续的意象对象。系统按 `theme × attention_state` 检索文本，而不是为全部主题复用同一句话。

## 文学语料层

文字内容分三层：

### FocusWave 原创

用于实时状态显示。要求明确标记为 FocusWave 原创，并通过内部审校表检查：状态准确度、意象一致性、语言自然度、唤醒度、歧义与文化敏感性。

### 审核文学回声

来自可核验的文学、哲学与公共领域文本。数据库记录原文、作者、作品、语言、可靠来源、中文翻译、版权状态、语义轴与适用状态。现代受版权保护作品只使用适量短引文，并按产品发布要求处理授权。

### 极简状态词

用于用户选择“极简”模式，例如：`稳定`、`轻移`、`外散`、`回收中`。这一层优先准确性。

## 研究依据

- Ganesan et al. (2022), focused attention meditation systematic review and meta-analysis: focused-attention meditation 以将注意持续指向一个对象或经验为核心，并涉及 default-mode、salience 与 executive-control networks。PMID 36067965。
- Feruglio et al. (2021), systematic review: mindfulness meditation 与 mind wandering 的研究总体显示长期练习可能减少走神，但研究设计和指标高度异质。PMID 34560133。
- Rahl et al. (2017), randomized experiment: attention monitoring 加 acceptance 的训练在 SART 中得到低于 monitoring-only 条件的 mind wandering，支持回收语言中的“觉察—允许—返回”结构。PMID 27819445。
- 2025 scoping systematic review (PMID 40800838): focused attention 被定义为以特定对象（如呼吸）培养持续集中、同时从干扰中脱离的基础性练习。

## 后续语料工作

1. 建立 `content/quotes/` 结构化语料库。
2. 按海、山、竹、雨、线香、夕照、月、云等意象建立文学来源索引。
3. 每条来源记录作者、作品、原文、可靠版本、翻译、版权状态、语义轴和适用 AttentionState。
4. 用至少两名人工审校者对原创状态文案进行自然度和状态可辨识度评分。
5. 产品测试时检查用户仅看一句文字能否区分四种状态，避免不同状态只表现为同义改写。
