# Typography

## 2026-10-09 当前统一字体规范

页面、分区、练习卡片和弹层的标题统一使用随站点发布的 Noto Serif SC（简体中文衬线字体）300 细字重。`--human` 与 `--heading` 指向同一字体，状态副句、引言和练习引导也使用这份字体，避免本机楷体造成字形混用。正文、导航、按钮、指标和时间沿用 `--ui` 无衬线字体。

`heading-typography.css` 同时覆盖一级至六级标题以及动态模块的标题类，禁用标题的合成字重。字号、行距、布局与交互沿用各模块已有规则。字体资源和许可证复用现有 `assets/fonts/noto-serif-sc/`，不增加字体下载。

## 2026-09-28 大标题规范（历史记录）

根据用户对在线大标题过粗的反馈，页面及弹层大标题改用随站点发布的 Noto Serif SC（简体中文衬线字体）300 细字重；正文、导航、指标和小字号人文文本保持原设置。标题字号、行距和布局沿用原规则。

入口为 `prototype/daily-focus-v1/heading-typography.css`；字体与开放许可证在 `assets/fonts/noto-serif-sc/`。使用同源字体与预加载，跨设备不再依赖本机是否安装霞鹜文楷。动态注入页面受同一标题规则约束。

以下文楷候选保留为历史探索记录，不作为当前网页的字体来源。

## 核心原则

FocusWave 使用“数据层 + 人文层”的双字体系统。

### 数据层

服务内容：

- Focus Index
- Confidence
- Data Quality
- SART / LIVE / 时间
- 参数、单位、标签

视觉要求：现代、清晰、精确、轻量、适合长时间屏幕阅读。优先使用成熟的 UI 无衬线字体与稳定的数字字形体系。

### 人文层

服务内容：

- `专注维持 / 轻度游移 / 明显分散 / 重新聚焦`
- FocusWave 原创短句
- 文学引用与译文

视觉要求：自然书写感、温度、屏幕适配性、清晰的汉字结构。优先测试现代文楷 / 今楷方向。

## 当前候选

- 霞鹜文楷 Screen：屏幕文楷参考候选
- 仓耳今楷：现代楷体参考候选
- 更轻、更克制的书写标题字：后续对比方向

## 字体层级

- 状态标题：人文层最大字号，承担状态命名
- 判词 / 短句：人文层第二层级，承担情绪与哲理表达
- 状态副句：轻量辅助文字
- 指标数字：数据层高可读数字
- 指标标签 / 时间 / LIVE：数据层小字号

页面保持单一主视觉中心。状态标题具有足够辨识度，指标保持轻量，流场继续承担主要视觉面积。

原则：**数据是现代的，人文是有温度的。**
