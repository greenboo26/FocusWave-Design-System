# FocusWave 设计原则

状态：Working Baseline / 持续迭代

本文件描述 FocusWave 当前目标状态。每一条原则都直接陈述界面应该呈现的结构、视觉行为、数据来源与语义层级。

## 0. 从根因定义设计

设计过程遵循四步：

1. 定义目标状态。
2. 找到决定目标状态的上层机制。
3. 直接修改主规则与相关系统文件。
4. 用效果图、交互原型、数据映射或实验结果验证。

规范优先描述“界面由什么构成、元素承担什么角色、变化由什么驱动”。

## 1. 首屏是一幅实时生成的数据作品

毫米波数据流场承担第一视觉中心。状态文字承担第二视觉中心。可信度与数据质量承担科学锚点。专业参数进入二级详情。

视觉层级：

1. 毫米波生成的艺术流场 / 数据形态
2. 当前注意状态与一条人文文本
3. Confidence / Data Quality
4. 专业特征与研究详情

## 2. 母版保持稳定

当前首屏母版采用：

- 大面积暖白 / 纸白留白
- 左上 FocusWave 标识
- 顶部中间任务名、时间、LIVE 会话信息
- 左侧状态名称、状态副句、人文短句或引文
- 右侧大面积毫米波细线流场
- 底部 `Focus Index / Confidence / Data Quality`

状态变化主要发生在线场、色彩、文字和细微动态上。稳定的空间骨架帮助用户形成长期视觉记忆。

## 3. 数据层现代，人文层有温度

界面采用双层字体与语义系统：

- 数据层：现代、清晰、精确、轻量，服务于数值、单位、任务状态与研究信息。
- 人文层：具有自然书写气质和屏幕适配性，服务于状态标题、短句、文学引用与译文。

两层共同形成“科学观测 + 人文感知”的品牌气质。

## 4. 意象是一套数据行为语法

山、海、竹、雨、云、飞鸟、蜻蜓、白马、线香、花、月、禅庭等意象通过数据视觉行为进入系统。

示例：

- 山：低频隆起、重心稳定、长线连续
- 海：横向推进、潮汐式周期、局部回卷
- 竹：节律清晰、方向挺拔、重复结构鲜明
- 雨：局部点状扰动、扩散与节律落点
- 飞鸟：局部轨迹外散、重心迁移
- 白马：快速连续的方向迁移与较强动势
- 线香：缓慢上升、内收与持续性
- 云：宽尺度漂移与柔和形变

## 5. 毫米波参数参与视觉生成

视觉形态保留真实数据结构，并经过审美压缩形成连续、优雅、可复现的视觉表达。

建议映射：

- 呼吸频率 → 大尺度波纹周期
- 呼吸振幅 → 大尺度起伏幅度
- 心搏 / beat 微动 → 极细二级纹理
- HRV / IBI 变化 → 局部间距与细纹节律变化
- 相位解缠 → 局部位移与流向
- movement → 局部偏折、剪切与连续性变化
- coverage / valid-window → 线场完整度与透明度
- signal confidence → 线条确定度
- 专注稳定性 → 全局秩序、方向一致性与聚合度
- 注意游移 → 相位错位、小型涡旋与局部外散
- 重新聚焦 → 局部扰动向整体秩序连续回收

## 6. 颜色同时承载意象与调节假设

颜色系统包含两层：

- 意象基础色：山、海、竹、雨、线香、夕照、花、夜等建立不同色域。
- 状态调节：稳定、游移、分散、恢复、疲惫调节明度、饱和度、综合色比例、局部对比与色彩统一性。

冷色、暖色和中性色共同构成完整主题空间。整体色彩保持柔和、低刺激、与留白协调。

颜色调节以“文献启发型设计假设”进入产品，并通过后续 A/B 或被试内实验建立 FocusWave 自身证据。

## 7. 文本系统连接状态与跨文化思想

文本内容包含：

- FocusWave 原创短句
- 中国古典文学
- 日本文学与俳句
- 英语、法语、拉丁语、希腊哲学等经典文本
- 其他具有明确出处、哲理性与低争议语境的文化材料

经典文本显示原文、中文译文、作者与作品。原创文本显示 FocusWave 原创标识。数据库记录来源、语义标签、语言、唤醒度、适配状态与审核状态。

## 8. 3D Attention Portrait 表达会话级画像

二维流场负责“此刻”；3D Attention Portrait 负责“这一段会话”。

3D 画像采用纯数据生成的浮雕或地形表面，支持拖动、旋转与回放。几何、细纹、局部起伏和表面连续性均来自真实毫米波与派生特征。

## 9. 科学语义保持分层

界面明确标注四类信息：

1. 直接测得的信号
2. 从信号推导的特征
3. 探索性综合指标
4. 经研究验证的状态解释

每一项指标都记录数据来源、算法版本、置信度与验证状态。产品文案随证据等级同步升级。
